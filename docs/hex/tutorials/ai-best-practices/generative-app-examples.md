# Generative app examples

Copy a prompt, paste it into a [Generative app](/docs/share-insights/apps/generative-apps), and let the Hex agent build from your workspace data.

info

Who it's for: anyone with **Can Edit** or higher project permissions who wants a starting point for a Generative app.

These prompts are written to travel. The agent picks the metric, grain, and dimensions from your warehouse and workspace context, and only asks when something is genuinely ambiguous. If it lands on the wrong table, @-mention the one you want and resubmit.

Filter or search for a use case, then copy a prompt and paste it into the App builder or the homepage prompt bar with the **Generate an app** intent.
