# User settings

Customize your personal Hex experience with user settings.

## Preferences[​](#preferences "Direct link to Preferences")

On the preferences panel, you can customize Hex with options specific to you.

### Agent preferences[​](#agent-preferences "Direct link to Agent preferences")

* Set your **Default agent data access** to control which sources agents start with in your conversations. Choose **Workspace default** to follow the default your Admin set, **All assets** to start with every source available through your permissions, or **Governed mode** to start with your workspace's [Governed mode](/docs/agent-management/governed-mode) configuration.
* Allow the Hex agent save memories automatically and use memories when responding.
* Customize how Hex agents respond across your projects with private, user-level instructions.

### Behavior[​](#behavior "Direct link to Behavior")

* Enable AI inline completions in code cells.
* Allow cells to occupy the full width of your notebook.
* Customize word-wrap and line-wrap settings for different cell types.
* Add line numbers to cells.
* Toggle on [Vim key bindings](https://vim.rtorr.com/) for SQL, markdown, and code cells. This setting applies globally to all Hex Notebook views you interact with. Note that when Vim key bindings are enabled, you'll need to use `shift + esc` to enter into [command mode](/docs/explore-data/notebook-view/keyboard-shortcuts#command-mode).

### Theme[​](#theme "Direct link to Theme")

* Select your preferred color theme for Hex. The default selection will match your system's theme preference.

## Notifications[​](#notifications "Direct link to Notifications")

Manage your notification preferences for different Hex interactions.

All email notifications are on by default. You can authenticate with your Slack account in order to customize notification preferences in Slack.

### Desktop notifications[​](#desktop-notifications "Direct link to Desktop notifications")

tip

Desktop notifications can be blocked by browser or operating system settings. If notifications aren't appearing:

* **Browser:** Check your browser's site settings for Hex
* **Operating system:** Make sure notifications are enabled for your browser in your system settings.

Under the desktop notification section, you can enable agent chat response notifications. When enabled, you'll receive a push notification when the agent completes a response or needs your input to proceed in an unfocused tab.

## API keys[​](#api-keys "Direct link to API keys")

Manage the tokens you have generated to access the Hex API. This section is only visible if your Admin has enabled [API access](/docs/administration/workspace_settings/workspace-security#enable-api-access).

For more information, view Hex's [API documentation](/docs/api-integrations/api/overview).
