# Beta roadmap

[Hex 4.0](/docs/hex-4-0/what-is-hex-4-0) is in beta, and some Hex features you may be familiar with aren't available yet. Here's what we're working on, what's next, and what's recently landed.

You can also open this list in Hex from the **Help** menu in any 4.0 project. *Last updated November 9, 2026.*

* In progress

  Scheduled runs & TasksRerun a project on a schedule or schedule an agent thread.
* In progress

  SecretsKeep your sensitive values, like API tokens or passwords, secret.
* In progress

  App editing improvementsEdit more of an app by hand, including React components and tables.
* In progress

  Improved Inspect workflowsTrace any result back to its data, logic, and code in fewer clicks.
* Up next

  App caching settingsSet how long a published app keeps cached results.
* Up next

  Chat with AppLet app viewers ask an agent questions about a published app.
* Up next

  Inspect published appsLet app viewers see the data and logic behind any element of a published app.
* Up next

  ReviewsRequest a review of your app before publishing.
* Up next

  CommentsLeave comments on cells and app components.
* Up next

  File exports in other formatsExport files in formats such as PPTX and XLSX.
