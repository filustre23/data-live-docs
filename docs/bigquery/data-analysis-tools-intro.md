# 分析和商業智慧工具簡介

使用 BigQuery 等資料平台時，分析和商業智慧工具對於從資料中發掘洞察資料至關重要。本文將介紹幾項可與 BigQuery 互補及整合的 Google 和第三方工具。

[連結試算表](https://docs.cloud.google.com/bigquery/docs/connected-sheets?hl=zh-tw)可讓您在 [Google 試算表](https://www.google.com/sheets/about/?hl=zh-tw)中存取、分析、共用並以圖表呈現數十億列的 BigQuery 資料。連結試算表介面可簡化與非技術專案利害關係人的協作流程，不需要額外匯出資料，還能簡化報表製作程序，並提供強大的存取控管功能。

[Looker](https://docs.cloud.google.com/bigquery/docs/looker?hl=zh-tw)
是 Google 的企業平台，提供資料視覺化和商業智慧服務。這項服務適用於進階資料分析、預測分析和自訂資料應用程式。也可以連線至其他公有雲中的交易資料庫。

[數據分析](https://docs.cloud.google.com/bigquery/docs/visualize-looker-studio?hl=zh-tw)是 Google 的資料視覺化和商業智慧工具。這項工具可直接從 Google Cloud 控制台連線至 BigQuery，有助於建立簡單的圖表、報表和資訊主頁。

[ODBC 和 JDBC 驅動程式](https://docs.cloud.google.com/bigquery/docs/reference/odbc-jdbc-drivers?hl=zh-tw)可讓您結合 BigQuery 的強大功能與現有工具和基礎架構，這些工具和基礎架構使用熱門的 ODBC 或 JDBC 連線。

[程式輔助分析工具](https://docs.cloud.google.com/bigquery/docs/programmatic-analysis?hl=zh-tw)可以執行程式碼，分析 BigQuery 中管理的資料。雖然 SQL 是功能強大的查詢語言，但 Python、Java 或 R 通常提供更簡化的表達方式來執行資料分析。這類工具包括 Jupyter Notebooks 和 Apache Zeppelin 等開放原始碼網頁應用程式。[Vertex AI Workbench](https://docs.cloud.google.com/gemini-enterprise-agent-platform/notebooks/workbench/introduction?hl=zh-tw) 是 Google 工具，提供 JupyterLab 筆記本環境，用於程式輔助分析。

您也可以使用多種熱門第三方工具 (例如 [Tableau](https://help.tableau.com/current/pro/desktop/en-us/examples_googlebigquery.htm) 和 [Microsoft Power BI](https://docs.microsoft.com/en-us/power-bi/connect-data/desktop-connect-bigquery)) 連線至 BigQuery。BigQuery Ready 計畫提供[經過驗證的合作夥伴解決方案完整清單](https://docs.cloud.google.com/bigquery/docs/bigquery-ready-partners?hl=zh-tw)。
