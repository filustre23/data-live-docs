# 分析和商業智慧工具簡介

您可以將分析和商業智慧 (BI) 工具與 BigQuery 整合，從資料倉儲中發掘可做為行動依據的洞察資料。多項工具可與 BigQuery 搭配使用，讓您建立互動式資訊主頁、自訂資料應用程式，或執行程式輔助分析，而不必移動資料集。

## 連結試算表

[連結試算表](https://docs.cloud.google.com/bigquery/docs/connected-sheets?hl=zh-tw)可讓您從 [Google 試算表](https://www.google.com/sheets/about/?hl=zh-tw)存取、分析、共用並以圖表呈現數十億列的 BigQuery 資料。連結試算表介面可簡化與非技術專案利害關係人的協作流程、不需額外匯出資料、簡化報表製作流程，並提供強大的存取控管功能。

## Looker

[Looker](https://docs.cloud.google.com/bigquery/docs/looker?hl=zh-tw) 是 Google 的企業平台，可用於資料視覺化和商業智慧。適用於進階資料分析、預測分析和自訂資料應用程式。也能連結其他公有雲中的交易資料庫。

## 數據分析

[數據分析](https://docs.cloud.google.com/bigquery/docs/visualize-looker-studio?hl=zh-tw)是 Google 的資料視覺化和商業智慧工具。這項工具可直接從 Google Cloud 控制台連結至 BigQuery，適合用來建立簡單的圖表、報表和資訊主頁。

## ODBC 和 JDBC 驅動程式

[ODBC 和 JDBC 驅動程式](https://docs.cloud.google.com/bigquery/docs/reference/odbc-jdbc-drivers?hl=zh-tw)可讓您將 BigQuery 的強大功能，與使用熱門 ODBC 或 JDBC 連線的現有工具和基礎架構結合。

## 程式輔助分析工具

[程式輔助分析工具](https://docs.cloud.google.com/bigquery/docs/programmatic-analysis?hl=zh-tw)可執行程式碼，分析 BigQuery 中管理的資料。雖然 SQL 是強大的查詢語言，但 Python、Java 或 R 通常能以更簡化、更具表達力的方式執行資料分析。這類工具包括 Jupyter Notebooks 和 Apache Zeppelin 等開放原始碼網頁式應用程式。[Vertex AI Workbench](https://docs.cloud.google.com/gemini-enterprise-agent-platform/notebooks/workbench/introduction?hl=zh-tw) 是 Google 工具，提供 JupyterLab 筆記本環境，可用於程式輔助分析。

## 第三方工具

您也可以使用 [Tableau](https://help.tableau.com/current/pro/desktop/en-us/examples_googlebigquery.htm) 和 [Microsoft Power BI](https://docs.microsoft.com/en-us/power-bi/connect-data/desktop-connect-bigquery) 等多種熱門第三方工具連線至 BigQuery。BigQuery Ready 計畫提供[經過驗證的合作夥伴解決方案完整清單](https://docs.cloud.google.com/bigquery/docs/bigquery-ready-partners?hl=zh-tw)。
