# Google Cloud Ready - BigQuery 合作夥伴

合作夥伴可透過 BigQuery 驗證計畫，驗證與 BigQuery 的整合，確保整合效果最佳。BigQuery 驗證計畫分為三個階段：

* **評估：**Google 團隊會在沙箱正式環境中執行一系列資料整合測試，並將結果與最佳做法和效能基準進行比較。
* **強化：**我們根據評估階段的結果，與合作夥伴攜手填補任何不足之處。
* **啟用：**我們與合作夥伴共同修訂現有說明文件，確保共同客戶擁有順利使用產品所需的一切資源。
